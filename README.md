# CCA Practice Mocks

Two full 60-question timed practice mocks for the Claude certification, in the real exam format, built for the [Autonomee](https://autonomee.ai) community.

- **Mock A** — `mock-a.html` (Hard Mock 01)
- **Mock B** — `mock-b.html` (Hard Mock 02)

Each is a single self-contained HTML file. Open it in a browser, sit it in one 2-hour block, and hit **Download .json** at the end to save your scored result. Progress is stored only in your own browser. Nothing is sent anywhere.

Live site: enabled via GitHub Pages.

Practice aid only. Not affiliated with the official exam.
