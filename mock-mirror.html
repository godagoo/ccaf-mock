How this sitting works

  • 60 items, 120 minutes. The clock starts when you press Start and auto-submits at zero.
  • Single answer only, exactly like the real Foundations exam. Every item asks you to select one option.
  • Right-click an option (or use the ⊘ icon) to strike it out. Strike the options you have ruled out so the real choice is a shorter decision.
  • Flag questions for review. Only change a flagged answer if you can name the specific reason the first one was wrong.
  • Hide the timer whenever the clock is a distraction. It keeps running and still auto-submits at zero; only the display goes away.
  • Navigation: the Review button shows your question list. There is no Back button. Click a question to return to it.
  • Read the QUESTION for the real constraint. If it says manage cost, cost is the answer, and options about the prompt are distractors.
  • Per-question comment box and a persistent notepad, same as the real interface.
  • Pass line: scaled 720 / 1000 (our scaled score is an approximation of the real scaling).
  • Closed book. No notes, no AI, no second screen. Sit it like the real day.
